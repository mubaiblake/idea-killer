# Founder Portrait（示例 / 脱敏版）

> 这是 idea-killer 在第一次运行时通过对话沉淀下来的画像。它直接决定后续每个 idea 的 founder-fit 分。
> 此示例为本仓库作者画像的脱敏版（具体数字打码、关键人格特征保留）。

---

## 基础信息

- **背景**：前大厂业务算法工程师（推荐 / LLM 方向，多年）
- **当前状态**：已离职，全职探索创业方向
- **生活基础**：积蓄足够个人生活短期无收入压力，**但可投入项目的预算非常有限**
- **跑道**：18-24 月（享受过程为前提，不是 6 月硬截止）

## 远期目标（接受三选一，全部认可）

- (a) Indie 规模化 ：独立产品做出付费规模
- (b) 拿融资组团队：被投资人看见后切入 venture-scale
- (c) 公司理想offer：用 ship + 输出换更好的回归路径

> ✅ 关键洞察：(a)(b)(c) 在前 12-18 个月的最优投入完全一致 —— 都是"被看见的 track record"。所以不需要先选路径，先建公开作品集 + 个人 IP。

## 硬约束（直接改 verdict）

| 约束                                 | 说明                             |
| ---------------------------------- | ------------------------------ |
| ❌ 内向                               | 不擅冷启动破冰、不愿做线下 BD / 视频出镜        |
| ❌ 没有圈内 co-founder                  | 不信任新认识的合伙人                     |
| ❌ 没有任何垂类 know-how                  | 跨境 / 健身 / 医美 / 金融 / 法律全都不在专业   |
| ❌ 不擅 BD / 出镜 / 内容增长                | 这是连续 9 个 ToC idea 被 Kill 的同一根因 |
| ❌ 不是 hot indie hacker              | 在开发者社区无身份                      |
| ✅ 全职时间 + 中等以上工程能力 + 大厂训练过的产品 sense | 这是真实可用的资产                      |

## 不愿做的事（execution-avoidance 红线）

- 长期视频出镜 / 直播
- 线下 BD / 跑展会 / 跑会议
- 24/7 客服 / 重交付服务
- 长期内容 IP 运营（每周更 + 数据指标）
- 给陌生人发冷邮 / 冷 DM

## 渠道偏好（什么我能持续输出）

- ✅ X 文字异步 / 英文受众
- ✅ GitHub 公开 ship
- ✅ 独立站 SEO 慢启动
- ⚠️ 小红书图文（不出镜）—— 可做但 AIGC 限流是已知风险
- ❌ 抖音 / TikTok / 视频
- ❌ 线下沙龙 / 圈子破冰

## 非对称优势（**真竞争层视角**，不是简历光环）

> ⚠️ 这一栏每条都标注了"在真竞争层是几"——简历标签 ≠ 优势。

| 我有什么 | 在真竞争层位置 |
|---|---|
| 推荐+LLM 工程能力 | 相对普通人是优势；相对赛道头部技术专家是 0 |
| 大厂业务 sense | 相对学生/野生开发者是优势；相对 0-1 创业者是平 |
| 全职时间 | 相对副业开发者是优势；相对 YC 团队是 0 |
| 用 Claude Code dogfood AI 工作流的真实经验 | 这条是少数真护城河，应被优先利用 |

## 历史失败结构（自我警示清单）

- ① 外行做高信任/高 know-how 垂直工具（已踩 3 次）
- ② 软价值订阅 + C 端不付费（已踩 4 次）
- ③ 通用 AI 6-12 月内会原生覆盖（已踩 4 次）
- ④ 渠道与画像不匹配（几乎所有 ToC idea 都中招）

> idea-killer 在 Phase 0 必须扫这 4 条，命中即综合分封顶 4。

## 决策语境

- 享受过程 > 短期收入
- 不能接受光环式推荐（必须落到真竞争层）
- 反复 Kill 第 N 次后，触发"是不是 idea 池本身有问题"的元层反思
