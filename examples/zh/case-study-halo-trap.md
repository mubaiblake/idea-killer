# 光环假设陷阱 —— 元案例

## 发生了什么

第 9 个 Kill 之后，作者尝试再推一个方向：「一人公司 AI 栈 / Claude Code 生态开发者工具——至少这个跟我工程背景对得上吧。」

他打字：

> "我的技术能力在开发者群体中并不强，这方面我也并没有什么优势。"

这是 30 天里第三次自我校准。skill 停下来。

## skill 怎么回应

它没有再给一个新 idea。它说的是：

> "你这第三次自我校准让我必须停下来。前面 9 个 idea 全 Kill 不是因为 idea 想得不够多。
>
> 是因为**我之前对你画像的'非对称优势'本身是光环假设**——相对于普通人是优势，相对于赛道里的真竞争者，你在每条赛道都是 0。
>
> 落到真竞争层（不是简历层），你在每条都没有护城河。
>
> 这是画像错配的直接产物，不是 idea 供给问题。"

然后它把作者自己看不见的那张表摆出来：

| 我之前推的方向 | 真实竞争层 | 你在这层的位置 |
|---|---|---|
| 跨境代运营 | 跨境老兵 + 圈内 co-founder | 没经验 → 0 |
| 健身 AI 教练 | CV/Pose Estimation 专家 + 健身教练 | 不在专业 → 0 |
| 跨境选品 Agent | 5-8 年实战卖家团队 | 同上 → 0 |
| 主动推送号 | 内容 IP 矩阵运营者 | 内向 + 不擅出镜 → 0 |
| 一人公司开发者工具 | Simon Willison / theo.gg / MCP 早期 contributor | 你刚承认不强 → 0 |

## skill 给的不是第 10 个 idea，是三条根本性选项

**1. 找联合创始人，不再单飞**
你的画像配一个"领域 know-how + 圈内人脉 + 外向 GTM"的合伙人就能解锁 α / D（大宗消费）/ 海外身份等高分方向。前 2-3 个月专门做这件事可能比再压测 10 个 idea 价值高 10x。

**2. 降级预期：做副业不做 venture**
你的画像下，年流水百万级公司概率 < 10%。但月入 ¥5-20k 的 indie SaaS / 内容订阅 / AI 工作流咨询服务概率有 30-40%。**关键不是 idea，是预期校准**。

**3. 蓄力 6 个月：进圈不创业**
全职 all-in 用前 6 个月**进入一个具体赛道的圈子**——加入一家跨境/AI infra/某垂类创业公司当早期员工或顾问，拿到 know-how + 人脉 + 1-2 个潜在 co-founder candidate，再决定 0-1。这不是放弃创业，是修补画像后再创业。

## 这才是 skill 真正的产品

普通 idea validator 在第 9 个 Kill 之后会接着给第 10 个、第 11 个、第 12 个新 idea ——每一个都是"全新搜索"。

第 10 个 Kill 看上去会跟前 9 个一样。第 11 个也是。

idea-killer 的 signatures 失败结构 dedup 抓到了作者自己当下看不见的模式：**输入端（idea）不是瓶颈，对 founder 的建模本身错了**。

skill 真正的产品不是 10 份 Kill 报告。是**让系统在你浪费下一个 sprint 之前，告诉你"你在优化错了的变量"**这个瞬间。

## 作者后来做了什么

作者没有再选 idea。他选了几乎没有任何 validator 会推的路线：

- **暂时不选创业方向**
- 用 12-18 个月公开 ship + X 文字异步 + 累积 track record
- 让方向从拿到反馈的事情里自己浮现出来

这条策略现在写在仓库中文 README 的 [meta-twist section](../../README_zh-CN.md#meta-twist第-10-个-kill-后才出现的真正价值)。
也是这个 skill 公开发布的真正动机：避免其他 founder 在错的变量上浪费 6 个月。

---

## 你怎么用这件事

如果你连续 Kill 了 3+ 个 idea：

- 大概率不是 idea 的问题
- 大概率是你自己的画像里"我以为我有"的优势其实只是光环
- 别再急着选第 4 个 idea，先做这件事：**回到真竞争层，问自己在那一层是几**

idea-killer 内置 `diagnostic-mode`：连续 3+ Kill 自动触发，对当前 PROFILE.md 跑一次同样的元复盘。如果发现光环，它会在你浪费下一个 sprint 之前把 gap 摆出来。
